# King Step — интерактивный прототип

## Запуск
Откройте `index.html` в современном браузере. Интернет нужен для загрузки Google Fonts и демонстрационных фотографий с Unsplash; сам сайт работает как статическая страница.

## Что интерактивно
- адаптивная навигация и мобильное меню;
- карточки направлений с модальным окном;
- кнопки выбора направления, расписания и тарифа с переносом выбора в форму;
- проверка имени, телефона, направления и согласия;
- демонстрационное сообщение после корректного заполнения формы (данные НЕ отправляются);
- выбор способа оплаты картой/СБП в демонстрационном режиме;
- FAQ и якорная навигация.

## Перед публикацией
Замените все демонстрационные данные: расписание, цены, преподавателей, отзывы, адрес, телефон, соцсети. Подтвердите список направлений. Фото являются иллюстративными, не изображают подтверждённую студию King Step.

## Реальная запись и платежи
Подключите backend/API или CRM, настройте серверную валидацию, защиту от спама, политику обработки персональных данных и безопасные уведомления. Для платежей используйте официальный checkout платёжного провайдера с поддержкой банковских карт и СБП; не собирайте карточные реквизиты в HTML.

## Рекомендуемая публикация
Для демонстрации: Netlify Drop или GitHub Pages (статический сайт). Для коммерческого запуска: домен, HTTPS, политика конфиденциальности и подключённая серверная часть. Пример доменов для проверки: kingstep.ru, kingstepkazan.ru, kingstepdance.ru, kingstep.рф — доступность не проверена.
